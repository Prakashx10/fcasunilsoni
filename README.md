# SUNIL KUMAR SONI & CO.
### Chartered Accountants

Official website for **SUNIL KUMAR SONI & CO.**, Chartered Accountants in Champa, Janjgir-Champa district, Chhattisgarh.

## Features
* **Obsidian Deep Blue & Brushed Gold theme** for an executive, trustworthy aesthetic.
* **Direct-execution Node.js Express server Monolith** (no webpack/vite/compilers required).
* **Fully decoupled data layer** via `data/data.json`.
* **Interactive constellation particle canvas background** on the hero banner.
* **IntersectionObserver-based scroll reveals** and slide-in visual elements.
* **Interactive tab-switcher for services** and accordion FAQ toggles.
* **Form validation and mock submission popup modal** for consulting enquiries.

## Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v18+)

### Installation & Run
1. Clone this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Boot the development server:
   ```bash
   npm run dev
   ```
4. Access the homepage at: `http://localhost:3000`
